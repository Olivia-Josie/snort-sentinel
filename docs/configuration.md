# Configuration des alertes email

Avant de lancer le script d'alertes, definis ces variables d'environnement :

export SENTINEL_EMAIL_FROM="ton_email@gmail.com"
export SENTINEL_EMAIL_PASSWORD="ton_mot_de_passe_application"
export SENTINEL_EMAIL_TO="destinataire@example.com"

Astuce : utilise un mot de passe d'application Gmail, pas ton mot de passe principal.
