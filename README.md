# Snort Sentinel
kit de detection d'instrusion reseau(IDS) accessible, base sur Snort, pour les petites structures (ecoles, PME, associations) sans expert em cybersecurite

## Auteur
Olivia Josie Kompane - Github : Olivia-Josie

## Objectif
Democratiser la detection d'intrusion reseau pour les structures qui n'ont pas ls moyens ou les competences de se proteger.
